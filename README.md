# LAS_IoT_applications
University project that used ESP32 and Arduino Nano 33 IoT to catch temperature, humidity and accelerometer data with microcontrollers

# Packages implementation
To the init the server, you'll need so node packets like : 
- express : simplify the implementation of the HTTP routes for API
- ws : create WebSocket to communicate with the Arduino Nano 33 IoT
- sqlite3 : SQLite server management
- net : TCP connexion management

Install the packets :  ```npm i express ws sqlite3 net chartjs```
